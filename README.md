🖥️ Sistema Web de Gestión de Mantenimiento e Inventario
Sistema web integral desarrollado para la Dirección Regional Agraria de Áncash que centraliza y optimiza los procesos de mantenimiento de equipos y gestión de inventario, facilitando la toma de decisiones estratégicas en la gestión de recursos agrarios.

✨ Características Principales
Gestión de Inventario: Registro y seguimiento completo de equipos y recursos

Control de Mantenimientos: Programación y seguimiento de mantenimientos preventivos y correctivos

Panel de Administración: Interfaz intuitiva para gestión de usuarios, equipos y reportes

Reportes Automatizados: Generación de informes técnicos para análisis y decisiones estratégicas

Sistema de Tickets: Para reporte y seguimiento de incidencias técnicas

🛠️ Tecnologías Utilizadas
Frontend: HTML5, CSS3, JavaScript

Backend: PHP

Base de Datos: MySQL

Servidor: Apache

Control de Versiones: Git
